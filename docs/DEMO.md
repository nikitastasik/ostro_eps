# Сценарий видео-скринкаста (4 минуты)

Сценарий повторяет демо-тур `/tour`: у каждого шага там есть кнопка «Открыть», которая ведёт прямо в нужное состояние, поэтому показ можно вести по туру. Отели для показа тур подбирает по текущим данным; ниже — те, что выбираются на свежем запуске.

Перед записью: `docker compose up --build`, открыть http://localhost:8080. Если демо уже «потрогали», нажать «Вернуть демо» внизу страницы `/tour`.

**Подводка (10 с).** «Фильтры знают звёзды и завтрак. Наши агенты знают, из окон какой стороны и с какого этажа видно море, в какие месяцы закат садится в море, где ночью тихо и сколько идти до пляжа в горку. И советуют гостю, какой номер просить».

У первого отеля «Чайка»: совет «номер с окнами на западную сторону», «закат из окна — ✓ с условием»: закат виден только из окон западной стороны, ≈48% номеров. Строка «↑ Выше следующего: закат с 1-го этажа, а не с 2-го». Нажать «Пожелание к бронированию» — готовый текст для отеля | Поиск | основное 5, доп. 1 |
