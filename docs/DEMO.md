# Сценарий видео-скринкаста (4–5 минут)

Перед записью: `docker compose up --build`, открыть http://localhost:8080. Если демо уже «потрогали», вернуть исходное состояние: `docker compose exec app python -m app.reseed && docker compose restart app`.

| # | Что показать | Где | Какое требование закрывает |
|---|---|---|---|
| 1 | Ввести «тихий номер с видом на закат недалеко от моря». Показать, как агент понял запрос (чипы), совет «номер с окнами на западную сторону, не ниже 7-го этажа» и пометки ✓/~/✗ с источниками и уверенностью. Удалить один чип — выдача пересчитается | Поиск | поиск по запросу, объяснение выбора |
| 2 | Ввести «тихий номер, с балконом» → «Не понял: «с балконом»» → ссылка «добавить характеристику» | Поиск | расширяемость |
| 3 | Открыть отель из выдачи. Панорама «что видно из окна»: переключить сторону и этаж ползунком; показать, как с этажом появляется море и закаты по месяцам | Карточка отеля | характеристика по геоданным |
| 4 | Раскрыть «Вид на море»: из чего уверенность (этажность из OSM, доля соседних зданий с известной высотой), источник, дата, срок годности. Карта: стрелки фасадов по шуму, путь до пляжа и профиль высот («туда 5 мин, обратно 6 мин и подъём 26 м») | Карточка отеля | хранение и достоверность |
| 5 | «Пересчитать агентами» → живой журнал: план → инструменты → решения → вопрос отельеру | Карточка отеля | агент сам выбирает источники |
| 6 | Войти `hotelier / hotelier123`, выбрать отель с вопросами. Ответить свободным текстом «Можно с собаками до 10 кг, 500 руб в сутки» → «Как агент поймёт ответ?» → «Отправить»: поля разложены, характеристика обновилась | Кабинет отельера | диалог с отельером |
| 7 | В кабинете — блок «источники расходятся»: отельер пишет «море из всех номеров», расчёт говорит «с 8-го этажа»; показать уточняющий вопрос агента. Там же «Верно» и «Исправить» у значений и «сильные стороны» отеля | Кабинет отельера | противоречия, кабинет отельера |
| 8 | Описать «Есть ли круглосуточная аптека в 10 минутах пешком» → «Скомпилировать» (рецепт `osm.poi_walk`) → «Создать» → агенты собрали для 164 отелей. Затем «Есть ли в номере чайник» → становится вопросом отельеру | Характеристики | расширяемость |
| 9 | «Построить» 50-метровый дом перед отелем с видом на море → агенты пересчитывают соседей → лента изменений («море видно с 5-го этажа → с 8-го»). «Демо: прошло 200 дней» → «Перепроверить устаревшее» | Агенты | актуализация |
| 10 | Сравнение трёх отелей: лучшие значения подсвечены | Сравнение | сравнение |
| 11 | Покрытие, доля вопросов отельерам, точность на отложенных выборках, сверка Солнца с PyEphem, кросс-валидация этажности | Метрики | метрики качества |

Короткая подводка для начала ролика: «Стандартные фильтры знают звёзды и завтрак. Наши агенты знают, что из окна 7-го этажа западной стороны в октябре закат над морем, что юго-восточная сторона ночью слышит железную дорогу, и что до пляжа 5 минут вниз, но обратно — подъём 26 метров».
